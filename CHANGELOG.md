# Changelog

## 0.1.0 — first public preview

- Native Linux Bluetooth panel using BlueZ and GTK 3.
- Optional Wayland layer-shell positioning; regular-window fallback.
- Connect, disconnect, scan, and interactive pairing prompts.
- Device status badges and battery values when reported by BlueZ.
- Connection notifications with right-click dismissal.
- Automatic desktop colors, four presets, and external JSON palettes.
- Per-user installer, app-menu launcher, optional autostart, and conservative uninstall.
- Optional Waybar, Hyprland, and Sway examples.

This is an early release. Real Bluetooth readback has been checked on Hyprland;
pairing across device types and GNOME/KDE-specific behavior need community testing.
